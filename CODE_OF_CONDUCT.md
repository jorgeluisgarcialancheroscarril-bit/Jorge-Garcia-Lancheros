# Código de conducta

Fertilízate es un proyecto educativo abierto. Para que sea un espacio seguro y acogedor:

- Trata a todas las personas con respeto, sin importar edad, género, origen o nivel de experiencia.
- Da y recibe críticas de forma constructiva; critica las ideas, no a las personas.
- Ten paciencia con quienes están aprendiendo: aquí se pregunta sin miedo.
- No se tolera el acoso, la discriminación ni el lenguaje ofensivo.
- Recuerda que parte de la comunidad son estudiantes menores de edad: mantén el contenido apropiado.

Quien incumpla estas normas podrá ser advertido y, si persiste, retirado del proyecto.
